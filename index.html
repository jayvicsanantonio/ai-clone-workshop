Before You Begin

This workshop is designed so you do one session per weekday (5 per week) for 6 weeks. Each session takes 30–60 minutes. By the end, you'll have a fully personalized AI system built inside your AI workspace that handles real work.

You don't need any coding experience. You don't need any prior AI experience. You just need your AI workspace and the willingness to actually do the exercises — not just read them.

Current Tool

Using ChatGPT. Change this if you switch workspaces.

What You Need

  • The latest ChatGPT Desktop app installed and signed in
  • A notes app or Google Doc for your "AI Clone Playbook" — a living document you'll build throughout
  • A list of your current weekly tasks/responsibilities (rough is fine)
  • 30–60 minutes per weekday for 6 weeks
  • Your willingness to be specific and honest about how you work

ChatGPT Desktop Setup Instructions

Use the current ChatGPT Desktop app, or chatgpt.com if your device cannot run the app. The workshop runs best inside one ChatGPT Project, where your Playbook, instructions, files, chats, and memory can stay tied to the same long-running effort.

1. Install and Sign In

  1. Go to the official ChatGPT download page or ChatGPT Desktop page. Do not use an old installer or a third-party download site.
  2. On macOS, use macOS 14 or newer with Apple Silicon (M1 or better). On Windows, use Windows 10 x64 or arm64 version 17763.0 or newer from the Microsoft Store.
  3. Open ChatGPT from Applications on Mac or the Start menu on Windows, then sign in. Windows app access and features may depend on your plan and your organization's Microsoft Store policy.
  4. Before Day 1, update or reinstall from the official page, then quit and reopen ChatGPT. If you plan to use Work with Apps on macOS, make sure ChatGPT for macOS is version 1.2025.057 or later.

2. Learn the Desktop Shortcut

  1. On macOS, press Option + Space to open the ChatGPT chat bar from anywhere on your desktop.
  2. On Windows, press Alt + Space while the app is open to use the companion window. If another app already uses that shortcut, change it in Settings > App > Companion window hotkey.
  3. Use the shortcut during the workshop whenever you catch yourself starting a task outside your AI Clone system.

3. Create Your Workshop Home

  1. Create one document named AI Clone Playbook in Google Docs, Notion, Word, Obsidian, or your notes app.
  2. Add these headings now: Clone Profile, Voice Profile, Prompt Library, Workflows, Quality Gates, and Maintenance Log.
  3. Create a folder named AI Clone Workshop for writing samples, screenshots, PDFs, spreadsheets, and files you want ChatGPT to analyze.

4. Make a Project

  1. In ChatGPT, click New project in the sidebar, name it AI Clone Workshop, and keep the workshop chats inside it.
  2. Open the Project menu, choose Project settings, and add this instruction:
    This project contains my personal AI Clone workshop. Use my Playbook, writing samples, prompt library, and feedback logs as the source of truth.
  3. Upload your Playbook and updated samples as you create them. Project file limits vary by plan: Free supports 5 files per project, Go and Plus support 25, and Edu, Pro, Business, and Enterprise support 40.

5. Set Instructions

  1. Use Project settings for workshop-specific instructions. Add this starter instruction there now:
    Help me build and maintain my AI Clone system. Ask for missing context, preserve my voice, and turn repeated work into reusable prompts and workflows.
  2. If you also use global custom instructions in Settings > Personalization, keep them short. Your Project instructions override global instructions inside this Project.
  3. Replace the starter instruction with your full Clone Blueprint at the end of Week 1.

6. Use Memory Intentionally

  1. When creating the Project, choose project-only memory if you want this workshop separated from the rest of your ChatGPT history.
  2. To use project memory, memory settings must be enabled for your account or workspace. If memory sources appear under a response, review them and correct, delete, or mark stale context as not relevant.
  3. For sensitive or compliance-bound work, do not rely on memory as the source of truth. Use your Playbook and approved files.

7. Optional: Apps and Files

  1. Use ChatGPT apps only when they help the workshop, such as Google Drive, Slack, Gmail, Outlook, Notion, Linear, Dropbox, or Box when you are allowed to share that context.
  2. In Projects, you can add supported app links as project sources or use connected apps from the tools menu. ChatGPT may ask before searching outside the Project.
  3. Keep file uploads curated. The latest web experience supports larger multi-file messages, but Project file limits are still separate from per-message upload limits.

8. Desktop Power Features

  • Work with Apps on macOS: ChatGPT can read supported coding, terminal, and text apps, and can generate reviewable code edits in supported IDEs.
  • Companion window: Use the desktop shortcut for quick prompts, screenshots, file uploads, image generation, web search, and new chats.
  • Canvas and files: Use Canvas for longer docs, code, and layouts, and use files when ChatGPT needs source material instead of memory.
  • Voice: Voice availability is platform- and plan-dependent. OpenAI retired Voice in the macOS desktop app on January 15, 2026; use chatgpt.com, mobile, or Windows when voice is available for your account.
Keep sensitive data out of ChatGPT unless you are allowed to share it and you understand your plan, workspace, app, Work with Apps, memory, and data controls. For this workshop, plain prompts, a curated Playbook, and a few approved writing samples are enough to complete the core system.

Clone Builder — Build It In One Week

Create your AI Clone's foundation: who you are, how you think, what you need.
Week Goal By Friday, you'll have a comprehensive "Clone Blueprint" — a master document that turns ChatGPT into a personalized partner that knows your context, goals, and preferences.
Day 1 The Brain Dump — Map Your World +

What You'll Do

Today is about getting important context out of your head and into a format ChatGPT can use. You'll create the personal context document that powers the rest of the workshop.

Step 1 — Write Your "About Me" Brief (15 min)

Open your AI Clone Playbook doc and write answers to these questions. Be specific — generic answers create a generic clone.

  1. What do you do for work? (Title, industry, company type, who you serve)
  2. What are your 3 biggest professional goals for the next 6 months?
  3. What are your 3 biggest personal goals?
  4. What does a typical work week look like? (Walk through Monday to Friday)
  5. What tools/platforms do you use daily? (Email, Slack, Notion, etc.)
  6. What are the recurring tasks you do every week?
  7. What are the tasks you hate doing but can't avoid?
  8. What's your communication style? (Formal? Casual? Direct? Warm?)

Step 2 — Feed It to ChatGPT (15 min)

Now take everything you wrote and paste it into ChatGPT Desktop with this prompt:

I'm building a personal AI Clone system with you — an AI partner trained on my context that can help me with daily work. Here's my full context. I want you to read this carefully, then do two things: 1. Summarize back to me who I am and what I need in a structured "Clone Profile" format 2. Ask me 10 follow-up questions that would help you assist me even better — things I probably forgot to mention Here's my info: [PASTE YOUR ABOUT ME BRIEF]

Step 3 — Refine the Profile (15 min)

Answer ChatGPT's follow-up questions. Then ask ChatGPT to produce a final "Clone Profile v1" that combines everything. Save this to your Playbook — it is the foundation for every later session.

Pro tip: Add this Clone Profile to your selected tool's personal or custom instructions using the setup guide above. That way new conversations start with your context already loaded.
Day 2 The Time Audit — Find Your 15 Hours +

What You'll Do

You can't reclaim time you haven't measured. Today you'll audit your recurring tasks and sort them by how ready they are for ChatGPT's help.

Step 1 — Task Inventory (20 min)

I want to audit my time to find 15+ hours a week I can buy back with AI. Here's what I need you to do: 1. Based on my Clone Profile, list every recurring task you think I do weekly (professional and personal). Make educated guesses — I'll correct you. 2. For each task, estimate the time per week. 3. Categorize each task into one of 4 buckets: - 🟢 AUTOMATE NOW: ChatGPT can do 80%+ of this right away - 🟡 ACCELERATE: ChatGPT can cut the time in half with the right setup - 🟠 AUGMENT: ChatGPT can help but I still drive - 🔴 HUMAN ONLY: Requires my physical presence or deeply personal judgment Format this as a table with columns: Task | Time/Week | Category | How ChatGPT Helps

Step 2 — Correct and Complete (15 min)

Review ChatGPT's list. Add tasks it missed. Correct time estimates. Push back where you disagree on categories — this conversation will teach ChatGPT how you think about your work.

Step 3 — Build Your Priority Queue (10 min)

Now sort all the 🟢 and 🟡 tasks by this formula: (time saved per week) × (ease of setup with ChatGPT). Give me a ranked priority list of the top 10 tasks to automate/accelerate first, with a one-line description of how we'll set each one up.

Save this priority list. It's your roadmap for the next 5 weeks.

Day 3 Style & Voice Calibration +

What You'll Do

The difference between a useful AI and one that feels "off" is voice. Today you teach ChatGPT exactly how you communicate.

Step 1 — Collect Writing Samples (15 min)

Gather 5–10 real examples of things you've written. The more variety, the better:

  • 2–3 emails you've sent (work emails, client emails, casual emails)
  • 1–2 social media posts or messages
  • 1 longer piece (blog post, report, proposal section)
  • Any Slack/Teams messages that feel very "you"

Step 2 — Voice Analysis

I'm going to give you samples of my real writing. I want you to analyze my communication style deeply and create a "Voice Profile" I can use in future prompts. Focus on: - Tone (formal ↔ casual spectrum) - Sentence structure (short & punchy vs. long & flowing) - Vocabulary level and any signature phrases I use - How I open and close messages - My personality that comes through (humor? directness? warmth?) - Any quirks or patterns Here are my writing samples: [PASTE YOUR SAMPLES] After analyzing, create a "Voice Profile" document I can paste into future prompts so ChatGPT writes like me.

Step 3 — Test It

Now test the voice profile immediately:

Using my Voice Profile above, draft a short email declining a meeting invitation because I have a scheduling conflict. Keep it 100% in my voice.

Compare ChatGPT's draft to how you'd actually write it. Give it feedback: "Too formal," "I'd never say 'I appreciate your understanding,'" "Add a bit more warmth." Iterate until it nails your voice. Save the final Voice Profile to your Playbook.

Pro tip: Put the final Voice Profile in your Project instructions and keep your best writing samples in the Project. If your workspace offers style or personalization settings, use the same samples there too.
Day 4 Build Your Master Prompt Library +

What You'll Do

Today you'll build reusable prompts for your top 5 priority tasks — the ones that will save you the most time starting next week.

Step 1 — Design Your First 5 Task Prompts

Take the top 5 tasks from your priority queue (Day 2). For each one, work with ChatGPT to create a reusable prompt template.

I need to create a reusable prompt template for this recurring task: Task: [DESCRIBE THE TASK] How often: [DAILY/WEEKLY/ETC] Current time spent: [X MINUTES/HOURS] What good output looks like: [DESCRIBE] What bad output looks like: [DESCRIBE] Create a prompt template I can reuse every time. Include: 1. Clear role/context instructions for ChatGPT 2. Placeholder slots I fill in each time (mark with [BRACKETS]) 3. Output format instructions 4. Quality checks / "make sure you..." rules 5. My voice profile considerations if relevant Make the prompt so good that I can get 80%+ quality output on the first try.

Repeat for all 5 tasks. Save each prompt template to your Playbook under a "Prompt Library" section.

Step 2 — Test Each Prompt Live

Pick a real example for each prompt and run it. Don't use hypothetical data — use an actual email you need to write, a real report you need to draft, a genuine social post you need to create. Grade the output: would you use it as-is, edit slightly, or start over?

Step 3 — Iterate Until 80%+ Quality

For any prompt that didn't hit 80%, refine it. Common fixes: add more context, provide an example of ideal output, be more specific about tone/length/format, or add constraints about what NOT to do.

Day 5 Assemble Your Clone Blueprint v1.0 +

What You'll Do

Bring everything together into one master document — your Clone Blueprint. This is the single document that turns any new ChatGPT conversation into YOUR personal assistant.

Help me assemble my final Clone Blueprint v1.0. Take all the pieces we've built this week and organize them into one clean, structured document: 1. CLONE PROFILE (who I am, what I do, my goals, my tools) 2. VOICE PROFILE (how I communicate, my style rules) 3. PRIORITY TASK LIST (what I need help with most) 4. PROMPT LIBRARY (my top 5 reusable prompts) 5. RULES & PREFERENCES (things ChatGPT should always/never do for me) For section 5, interview me: ask me 10 questions about my preferences for how AI should assist me — things like: do I want ChatGPT to ask clarifying questions or just take its best shot? Should ChatGPT default to short or detailed responses? How should ChatGPT handle tasks it's unsure about? Format the final document so I can paste it into my selected tool's custom instructions, my AI Clone Project, or the start of any conversation.

Once assembled, paste the key sections into Instructions for your selected tool using the setup instructions above. Also upload the full Playbook to your AI Clone Workshop Project so project chats can use the complete context.

Week 1 Checkpoint: You should now have a Clone Profile, Voice Profile, Time Audit, Priority Queue, 5 tested prompt templates, and a complete Clone Blueprint. If any piece feels thin, spend extra time on it before moving to Week 2.

Day 6 Email & Communication Takeover +

What You'll Do

Email is the #1 time-suck for most professionals. Today you'll set up ChatGPT as your email drafting partner.

I want to create a system for drafting emails quickly. Here are the types of emails I send most often: 1. [TYPE 1 — e.g., "client follow-ups after meetings"] 2. [TYPE 2 — e.g., "internal status updates to my team"] 3. [TYPE 3 — e.g., "cold outreach to potential partners"] 4. [TYPE 4 — e.g., "scheduling/logistics coordination"] 5. [TYPE 5 — e.g., "responding to inbound inquiries"] For each type, create a reusable prompt template that includes: - Context I need to provide each time (keep it minimal — bullet points only) - Tone/voice instructions from my Voice Profile - Default length and format - Subject line generation Make each template so fast to use that I spend under 60 seconds providing inputs.

Step 2 — Process Real Emails

Open your inbox right now. Pick 5 emails that need responses. For each one, paste the email into ChatGPT with the appropriate template. Time yourself — you should be drafting replies in 1–2 minutes each instead of 5–10.

Step 3 — Build a "Quick Reply" Cheat Sheet

Based on my communication patterns, create a "Quick Reply Cheat Sheet" — a list of 15 common email scenarios with pre-written responses in my voice that I can copy-paste with minor edits. Include: - Scheduling confirmations - Meeting declines - Thank you follow-ups - "I'll get back to you" placeholders - Introductions/referrals - Request for more information And any other patterns you've noticed from my profile.
Day 7 Content Creation Sprint +

What You'll Do

Set up ChatGPT as your content creation partner — whether that's social media, blog posts, newsletters, or internal documents.

Step 1 — Content Strategy Session

I need to create content regularly for my work. Here's my content landscape: - Platforms I post on: [LIST THEM] - Topics I cover: [LIST THEM] - Frequency goals: [e.g., "3 LinkedIn posts/week, 1 newsletter/month"] - My content goals: [e.g., "build authority," "drive leads," "engage community"] - Audiences: [WHO READS MY STUFF] Create a content workflow system for me: 1. A weekly content calendar template 2. An "idea generation" prompt I can run whenever I'm stuck 3. A "draft from idea" prompt for each platform 4. A "review and polish" prompt for final editing

Step 3 — Build a Content Bank

Generate 20 content ideas for me based on my expertise, audience, and goals. For each idea, give me: - A headline/hook - 3 key points to cover - Which platform it's best for - Estimated time to create with ChatGPT's help Organize by theme/pillar so I can batch-create related content.
Day 8 Research & Analysis Accelerator +

What You'll Do

Learn to use ChatGPT for research, analysis, and decision-making support — turning scattered reading into structured insight.

Step 1 — Research Prompt Templates

I frequently need to research topics for my work. Create 3 research prompt templates: 1. QUICK RESEARCH: For when I need a fast overview of a topic (5-min result) - Structured as: Key facts → Pros/Cons → My recommended action 2. DEEP DIVE: For when I need thorough analysis (detailed result) - Structured as: Background → Current state → Key players → Trends → Opportunities → Risks → Sources to check 3. COMPETITIVE ANALYSIS: For comparing options/tools/vendors - Structured as: Comparison matrix → Strengths/Weaknesses → Price analysis → Recommendation with reasoning Make each one reusable with [BRACKET] placeholders.

Step 2 — Run a Real Research Task

Pick something you actually need to research this week. Use the appropriate template. If web search is available in your ChatGPT account, ask ChatGPT to find current information and include sources. If not, paste the sources you want it to analyze.

Step 3 — Decision Framework

I have a decision to make: [DESCRIBE THE DECISION] Walk me through this using a structured decision framework: 1. Clarify the decision and what's really at stake 2. List all viable options (including ones I haven't considered) 3. Define my evaluation criteria based on my goals and values (reference my Clone Profile) 4. Score each option against the criteria 5. Identify what additional information would change the answer 6. Give me your recommendation and reasoning Be honest — challenge my assumptions if you see blind spots.

Day 23 Advanced Prompting Techniques +

What You'll Do

Level up your prompting with advanced techniques that get dramatically better results.

Technique 1: Chain of Thought

Add "Think step by step before answering" to analytical prompts. This dramatically improves accuracy on complex problems.

Technique 2: Role + Anti-Role

You are an experienced [ROLE] who specializes in [SPECIALTY]. You are NOT a generic AI assistant — you have strong opinions backed by deep expertise. Don't hedge or give wishy-washy answers. Tell me what you actually think is the right move and why.

Technique 3: Few-Shot Examples

Always provide 1-2 examples of ideal output when quality matters. ChatGPT mimics patterns extremely well.

Technique 4: Structured Output Formats

Always specify exactly how you want the output formatted: "Use headers, bullet points, and bold key terms" or "Write in prose paragraphs, no bullets" or "Format as a table with columns for X, Y, Z."

Technique 5: Iterative Refinement

Instead of trying to get the perfect output in one prompt, use a sequence: "Draft it → Now make it shorter → Now make the opening stronger → Now add a specific example in paragraph 2."

Practice

Take your 3 weakest-performing prompts and apply these techniques. See if the output improves.
